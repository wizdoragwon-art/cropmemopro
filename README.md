# Crop Memo Pro — 오프라인 현장 수집 PWA

폰·패드에서 **인터넷 없이 야장 데이터를 저장**하고, 연결되면 **Google Sheets로 동기화**하는 설치형 웹앱(PWA)입니다. 앱스토어·APK 없이 링크만으로 "홈 화면에 추가"해서 씁니다.

## 버전 표시
홈 화면 제목 아래에 **`종자연구소 야장 · 버전정보 26.8.8`** 처럼 업데이트 날짜가 표시됩니다(연.월.일). 앱을 수정해 다시 배포할 때는 두 곳의 날짜만 바꾸면 됩니다.

- `app.js` 맨 위의 `var APP_VERSION = '26.8.8';`
- `sw.js` 의 `const CACHE = 'cropmemo-26.8.8';` (같은 값으로 맞추면 예전 캐시가 자동으로 정리됩니다)

## 폴더 구성
```
index.html            앱 화면(셸)
app.js                로직: 오프라인 저장(IndexedDB)·수집·선발·조사일·동기화·CSV
styles.css            디자인 토큰·컴포넌트
icons.js              오프라인 아이콘(인라인 SVG)
xlsx.min.js           엑셀(.xlsx) 파서(SheetJS · 오프라인)
guide/                사용 가이드 화면 캡처(첫 실행 안내 · 약 0.9MB)
ocr/                  OCR 엔진(Tesseract · 한글+영문 데이터 · 오프라인 · 약 9.7MB)
pdf/                  PDF 읽기 모듈(pdf.js · 오프라인 · 약 1.5MB)
manifest.webmanifest  설치 정보(이름·아이콘)
sw.js                 서비스워커(오프라인 캐시)
icons/                앱 아이콘(192·512·maskable·apple)
```

## 1) 실행/호스팅
서비스워커는 `file://`에서는 동작하지 않습니다. **로컬 테스트**는 폴더에서:
```
python3 -m http.server 8000
```
→ 브라우저에서 `http://localhost:8000` 접속.

**팀에 배포**하려면 정적 호스팅에 폴더를 올려 URL을 만드세요(무료). 예: GitHub Pages
1. GitHub에 저장소 생성 → 이 폴더의 파일들을 업로드
2. Settings → Pages → Branch: main / (root) 저장
3. 몇 분 뒤 나오는 `https://<계정>.github.io/<저장소>/` 주소를 폰·패드에서 열기

(Netlify Drop, Vercel, Cloudflare Pages, Google Sites 등 어떤 정적 호스팅도 가능합니다.)

## 2) 설치 (홈 화면에 추가)
- **Android(크롬)**: 주소 열기 → 메뉴(⋮) → "앱 설치" 또는 "홈 화면에 추가"
- **iPad/iPhone(사파리)**: 공유 버튼 → "홈 화면에 추가"

설치하면 앱 아이콘으로 실행되고 전체화면으로 뜹니다.

## 3) 오프라인
첫 로딩 이후에는 인터넷이 없어도 실행됩니다. 입력값은 즉시 기기 안(IndexedDB)에 저장되고, 앱을 껐다 켜도 유지됩니다. 상단 홈의 동기화 카드가 **오프라인 · 미전송 N건**으로 상태를 보여줍니다.

## 4) 동기화 연결 (선택 · 구글 드라이브 또는 OneDrive)
사무실 시트로 올리려면 함께 제공된 **`CropMemoPro_GAS_Code.gs`** 를 배포하세요.
1. `sheets.new` → 확장 프로그램 → Apps Script → 코드 붙여넣기 → `setup` 1회 실행
2. 배포 → 새 배포 → 웹 앱 → 액세스 "모든 사용자" → **`/exec` URL** 복사
3. 앱의 **설정 탭 → 동기화 URL**에 붙여넣고 저장 → "연결 테스트"로 확인
4. 이후 온라인이면 자동 전송되고, 홈/내보내기에서 "지금 동기화"로 즉시 전송

동기화하면 **모든 과제**가 각자의 폴더로 올라갑니다. 각 과제 폴더에 들어가는 것:

| 파일 | 올라가는 때 |
| --- | --- |
| `과제명_라벨목록_날짜.csv` | **항상** — 조사값이 아직 없는 과제도 폴더가 만들어집니다 |
| `과제명_처음라벨-마지막라벨_날짜.csv` (야장) | 조사값이 하나라도 있을 때 |
| 사진·그림 jpg | 새로 찍은 사진이 있을 때 |

같은 이름의 파일은 덮어써지므로 동기화를 반복해도 중복이 쌓이지 않습니다. 전송이 안 된 과제가 있으면 완료 안내 대신 **"일부 과제 전송 실패 · 과제명"** 이 뜹니다.

> 참고: Apps Script 웹앱은 브라우저 CORS 정책상 배포 액세스가 "모든 사용자"여야 응답을 읽습니다. 실패해도 데이터는 로컬에 안전하게 남아 다음 연결 때 다시 전송됩니다.

## 5) 사용 가이드 (첫 실행 안내)
앱을 **처음 열면** 실제 앱 화면 캡처 17장으로 된 안내 팝업이 뜹니다. 좌우로 밀거나 아래 버튼으로 넘깁니다.

순서: 환영 → **새 과제 · 불러오기** → **과제 생성 3단계**(과제 정보 · 세대 · 형질세트) → 엑셀·CSV 미리보기 → 형질 불러오기 → 과제 수정(계통 표) → 조사 화면 읽는 법(①라벨번호 ②형질 ③필드맵) → 형질 수정 → 값 입력·스와이프(좌우=개체, 상하=라벨번호) → 사진·그리기·음성 → 필드맵 → **선택 과제·전체 과제 내보내기** → **동기화 연결·사진 화질** → 기기 백업 → 준비 완료

- 일부 장에는 본문 아래 **연한 초록 보조 박스**로 알아두면 좋은 점(예시 과제 안내, 불러오기가 받는 파일, 모음 폴더 병합, 사진 파일명·화질, 가이드 다시 보기, 기기 백업 브라우저 안내)을 덧붙였습니다.
- 화면을 바꾸면 `guide/` 의 캡처도 함께 다시 찍어야 안내와 그림이 어긋나지 않습니다.

- 마지막 장의 **"다음부터 이 안내를 보지 않기"** 는 기본으로 켜져 있습니다. 그대로 `시작하기`를 누르면 다음 실행부터 뜨지 않고, 체크를 끄면 다음에도 다시 안내합니다. 오른쪽 위 ✕(건너뛰기)로 닫아도 다시 뜨지 않습니다.
- 언제든 **설정 탭 맨 아래 → `사용 가이드 다시 보기`** 로 볼 수 있습니다.
- 캡처 이미지는 `guide/` 폴더에 있고 가이드를 열 때만 불러옵니다. 한 번 본 뒤에는 오프라인에서도 보입니다.
- 화면을 크게 바꾼 뒤에는 캡처도 다시 찍어 `guide/` 의 같은 파일명으로 바꿔 넣으면 됩니다.

## 5-1) 설정 화면 구성
설정 탭은 세 덩어리입니다.

| 구분 | 들어 있는 것 |
| --- | --- |
| **백업** | 기기 백업 폴더 · 동기화(사용 여부 · 저장 위치 · URL · **동기화 전송 사진 화질** · 연결 테스트/저장 · 동기화 방법) |
| **기기 설정** | **야장 저장 사진 화질** · 진동 피드백 · 사용 가이드 다시 보기 |
| — | 모든 로컬 데이터 삭제 (초기화) |

- **공유 토큰** 칸은 OneDrive를 골랐을 때만 나옵니다(구글 드라이브에서는 숨김).
- 사진 화질은 **두 곳**에 있고 서로 다릅니다.
  - **야장 저장 사진 화질**(기기 설정) — 촬영한 사진을 기기에 저장할 때의 화질
  - **동기화 전송 사진 화질**(백업) — 동기화로 **보낼 때만** 줄여 보냅니다. 기기에 저장된 사진은 그대로이고, 기기 백업에도 영향이 없습니다. 모바일 데이터로 보낼 때 `저화질`을 고르면 전송량이 크게 줄어듭니다(예: 904KB → 531KB).

### 사진 화질 단계
두 설정 모두 같은 두 단계를 씁니다. 기본은 **원본**입니다.

| 단계 | 저장 방식 | 사진 1장 | 기기 저장(내부) |
| --- | --- | --- | --- |
| 저화질 | 2600×1950 · 품질 0.92 로 줄임 | 약 520KB | 약 700KB |
| **원본 (기본)** | **카메라 JPEG를 다시 압축하지 않고 그대로** | **2~5MB** | **2.7~6.7MB** |

- **원본**은 재압축을 하지 않으므로 화질 손실이 전혀 없습니다. 원본이 JPEG가 아니거나 14MB를 넘으면 3600px·품질 0.95로 줄여 담습니다.
- 저화질로 줄일 때는 **고품질 리샘플링**(`imageSmoothingQuality: 'high'`)을 씁니다.
- 설정 화면 아래에 **기기 저장 사용량 / 사용 가능 용량**이 표시됩니다.
- 이미 찍어 둔 사진의 화질은 바뀌지 않습니다. 설정을 바꾼 뒤 찍는 사진부터 적용됩니다.

**원본으로 쓸 때 알아둘 점**

- 사진 100장이면 기기 안에서 약 300~700MB를 씁니다. 설정 화면의 사용 가능 용량을 가끔 확인하세요.
- **백업은 `폴더에 저장`을 쓰세요.** 폴더 저장은 과제 하나씩 써 내려가며 메모리를 비우므로 사진이 많아도 안전합니다. ZIP은 전부 메모리에 올려 압축하므로 사진이 아주 많으면 실패할 수 있고, 300MB를 넘으면 폴더 저장을 권하는 안내가 뜹니다.
- 같은 폴더로 다시 백업하면 **이미 저장된 사진은 건너뜁니다**(파일명·크기 동일). 원본 화질에서 특히 효과가 큽니다.
- 드라이브 동기화는 사진을 한 장씩 보내며 이미 보낸 사진은 다시 보내지 않지만, 장당 용량이 커져 전송 시간과 데이터 사용량이 늘어납니다. 사진이 많다면 사무실 와이파이에서 동기화하시길 권합니다.

## 6) 기기 백업 (홈 · 동기화 카드 아래)
홈 화면의 **기기 백업** 버튼을 누르면 **폴더 선택창이 바로 뜨고**(중간 팝업 없음) 고른 폴더에 **모든 과제**를 저장합니다. 한 번 고른 폴더는 기억되어 다음부터는 누르는 즉시 저장됩니다.

```
CropMemo/
├─ 백업정보.txt                       백업 일시·과제별 건수
├─ 2026 하계 시험/                     ← 과제 모음(폴더)에 묶인 과제는 모음 폴더명
│   └─ 오이 내병성 육종/
│       ├─ 오이 내병성 육종_야장_2026-08-07.csv
│       ├─ 오이 내병성 육종_라벨목록_2026-08-07.csv
│       └─ 사진/  …_라벨번호_개체번호_형질_촬영일자.jpg
└─ 토마토 당도 육종/                   ← 묶이지 않은 과제는 과제명 폴더
    ├─ 토마토 당도 육종_야장_2026-08-07.csv
    ├─ 토마토 당도 육종_라벨목록_2026-08-07.csv
    └─ 사진/ …
```

저장 방법은 두 가지입니다.

**① 폴더에 저장** — 저장할 폴더를 직접 고릅니다(데스크톱 크롬·엣지, 안드로이드 크롬 132 이상).

- **PC**: 고른 폴더 아래에 `CropMemo/…` 폴더와 파일을 실제로 만들어 씁니다. 선택한 폴더는 기억되어 다음 백업부터는 바로 저장됩니다.
- **안드로이드**: 폴더 만들기가 막혀 있는 경우가 많아(`getDirectoryHandle` → `NotAllowedError`), 이때는 **고른 폴더에 파일을 하나씩 나란히** 저장하고 폴더 경로를 파일명 앞에 붙여 구분합니다. 압축을 풀 필요가 없습니다.
  ```
  CropMemo_백업정보.txt
  CropMemo_26 고추 시험_26년 고추 시교_야장_2026-08-08.csv
  CropMemo_26 고추 시험_26년 고추 시교_라벨목록_2026-08-08.csv
  CropMemo_26 고추 시험_26년 고추 시교_사진_T1-001_1_초장_2026-08-08.jpg
  ```
  다운로드 폴더가 막혀 있으면 **직접 만든 폴더**(예: 내장 저장공간/CropMemo)를 골라 보세요. 폴더 만들기가 되는 곳이면 ①의 PC와 같은 폴더 구조로 저장됩니다.
- **쓰기 권한**: 폴더 선택창에서 고른 폴더의 권한을 그대로 씁니다. 별도의 권한 확인 팝업은 띄우지 않고, 쓸 수 없으면 개별 파일 저장 → ZIP 순서로 자동으로 넘어갑니다. 한 번 저장에 성공한 폴더는 기억되어 다음부터는 바로 저장됩니다.

**② ZIP 저장** — 위 폴더 구조를 그대로 담은 압축 파일 하나(`CropMemo_백업_날짜.zip`)를 다운로드 폴더에 저장합니다. 파일을 눌러 압축을 풀면 폴더가 그대로 만들어집니다. 폴더 선택을 지원하지 않는 브라우저에서는 이 방법만 나옵니다.

> 파일 쓰기까지 막히는 기기에서는 모아둔 자료를 버리지 않고 자동으로 ZIP 저장으로 넘어갑니다.

**같은 사진은 건너뜁니다** — 폴더에 저장할 때, 사진은 **파일명과 크기가 같으면 다시 쓰지 않습니다.** 같은 폴더로 반복 백업해도 사진이 다시 복사되지 않아 빠르고, 사진을 새로 찍거나 그림을 덧그려 내용이 바뀐 것만 갱신됩니다. 완료 안내에 `같은 사진 N장 건너뜀` 으로 표시됩니다. (CSV는 내용이 바뀌므로 항상 덮어씁니다. ZIP 저장은 매번 새 압축 파일이라 해당 없습니다.)

**폴더 미리 정해두기** — 설정 탭 아래 **`기기 백업 폴더`** 에서 백업 폴더를 미리 고를 수 있습니다. 지금 기억하고 있는 폴더 이름이 함께 표시되고, `해제`를 누르면 다음 백업 때 다시 고르게 됩니다. 폴더 선택을 지원하지 않는 브라우저에서는 그 사실을 안내합니다.

**저장 폴더가 없어진 경우** — 기억해 둔 폴더를 기기에서 지웠으면, 백업을 누를 때 그 폴더가 아직 있는지 먼저 확인하고 없으면 **폴더 선택창을 다시 띄웁니다.** (예전에는 `InvalidStateError` 안내와 함께 ZIP 다운로드로 넘어갔습니다.)

**파일 수정날짜** — ZIP 안의 각 파일에 실제 시각이 들어갑니다. CSV는 백업한 시각, 사진·그림은 **찍은(수정한) 시각**입니다. 사진 ZIP 내보내기도 같습니다. (예전에는 시각을 비워 두어 압축을 풀면 `1980-00-00` 으로 보였습니다.)
- 오프라인에서도 됩니다. 동기화 설정과 무관하게 동작합니다.
- 마지막 백업 시각은 홈의 기기 백업 카드에 표시됩니다.

### 폴더 구조는 어디서나 동일합니다
기기 백업 · 사진 ZIP 내보내기 · 드라이브(OneDrive) 동기화가 모두 같은 경로 규칙을 씁니다.

| 상황 | 저장 경로 |
| --- | --- |
| 과제 모음(폴더)에 묶인 과제 | `CropMemo / 모음 폴더명 / 과제명 /` |
| 묶이지 않은 과제 | `CropMemo / 과제명 /` |

- **내보내기 탭**: `사진 ZIP 내보내기 (이 과제)` 외에, 현재 과제가 모음에 묶여 있고 그 모음에 과제가 2개 이상이면 **`모음 전체 ZIP`** 버튼이 함께 나타나 모음 안의 모든 과제를 한 ZIP에 담습니다.
- **구글 드라이브 동기화**: 모음 폴더를 적용하려면 `CropMemoPro_GAS_Code.gs` 를 **다시 붙여넣고 재배포**하세요(기존 배포도 그대로 동작하며, 이 경우 모음 폴더 없이 예전 경로에 저장됩니다).
- **OneDrive 동기화**: 앱만 업데이트하면 바로 적용됩니다.

## 7) 과제 불러오기 (홈 · `+ 새 과제` 오른쪽)
홈의 **불러오기** 버튼으로 기기에 저장해 둔 백업에서 과제를 되살립니다. 받을 수 있는 것:

| 고르는 것 | 설명 |
| --- | --- |
| 백업 ZIP | `CropMemo_백업_날짜.zip` — 안에 든 모든 과제를 한 번에 |
| 과제 폴더 · 모음 폴더 | 폴더 안의 CSV·사진을 모두 읽습니다(하위 폴더 포함) |
| 야장 CSV | 라벨·형질·조사값을 되살립니다 (K열 `형질 수집형태`로 형질 종류까지) |
| 라벨목록 CSV | 라벨 구성만 되살립니다 |

- `파일 선택`은 ZIP·CSV를 여러 개 한 번에 고를 수 있고, `폴더 선택`은 폴더째로 읽습니다(폴더 선택은 크롬·엣지).
- **모음 폴더 구조도 그대로 복원**됩니다. 폴더 이름이 같으면 기존 모음에 들어갑니다.
- 불러온 과제는 **새 과제로 추가**되며 기존 과제는 지워지지 않습니다. 이름이 겹치면 `(불러옴)`이 붙습니다.
- **작물은 과제명에서 알아냅니다.** `26년 고추 탄저병 시험` → `고추`. 과제명에서 못 찾으면 **모음 폴더명**에서 찾고, 그래도 없으면 `미분류`로 둡니다. 불러오기 전 미리보기에 알아낸 작물이 함께 표시되고, 나중에 과제 수정 → 작물에서 바꿀 수 있습니다.
  - 찾는 대상: 기본 작물 6종(토마토·고추·무·배추·수박·오이) + **이미 쓰고 있는 작물명**(직접 추가한 작물 포함).
  - `무` 처럼 한 글자인 작물은 앞뒤가 한글이면 건너뜁니다 — `배추 무름병` 은 `배추`, `무름병 저항성` 은 `미분류`, `가을 무 수량성` 은 `무` 로 들어갑니다.
- 형질의 종류는 CSV의 **K열 `형질 수집형태`** 를 그대로 따릅니다. 그 열이 없는 옛 파일만 값·단위에서 추정합니다.
- 등급 척도·항목 목록은 CSV에 없어 실제로 쓰인 값에서 되살립니다. 불러온 뒤 **과제 수정 → 형질 편집**에서 한 번 확인하세요.
- 사진 jpg는 파일명(`…_라벨번호_개체번호_형질_일자.jpg`)으로 개체를 찾아 붙입니다.

## 8) 내보내기
**선택 과제**와 **전체 과제**로 나뉘어 있습니다. 저장 위치는 브라우저의 다운로드 폴더이고, 폴더 구조는 기기 백업과 동일합니다(`CropMemo / [모음 폴더명 /] 과제명 /`).

| 구분 | 버튼 | 내용 |
| --- | --- | --- |
| 선택 과제 | 선택 과제 파일 (CSV, 사진) 다운로드 | 야장 CSV + 라벨목록 CSV + 사진을 ZIP 하나로 |
| | 선택 과제 CSV 다운로드 | 야장 CSV 파일 한 개 |
| | 선택 과제 사진 ZIP 다운로드 | 사진만 ZIP으로 |
| | 사진 개별 선택 다운로드 | 사진을 눈으로 골라 jpg로 낱개 저장 |
| 전체 과제 | 전체 과제 파일 ZIP 다운로드 | 모든 과제의 CSV·사진을 ZIP 하나로 |
| | 전체 과제 CSV 파일 다운로드 | 모든 과제의 CSV만 ZIP으로 |
| | 전체 사진 ZIP 다운로드 | 모든 과제의 사진만 ZIP으로 |

야장 CSV는 UTF-8 BOM 롱포맷(엑셀 호환)입니다.

| 열 | 내용 |
| --- | --- |
| A~G | No. · 라벨번호 · 품종명/Pedigree · 세대 · 반복 · 개체 · **조사일** |
| H~J | 형질 · 값 · 단위 |
| **K** | **형질 수집형태** — 수치형 · 비율(%) · 등급 · 카운터 · 항목형 · 날짜형 · 문자형 |
| L~M | 조합, 계통 선발 · 개체 선발 |

K열은 **불러오기에서 형질의 종류를 그대로 되살리는 데** 씁니다. 이 열이 없는 옛 CSV도 불러올 수 있고, 그때는 값에서 종류를 추정합니다. 등급의 척도와 항목형의 항목 목록은 CSV에 없으므로 실제로 쓰인 값에서 되살립니다(1·3·5·7·9 같은 흔한 척도는 자동으로 맞춥니다).

> 동기화는 **설정 탭**에서 켜고 끄며, 온라인이면 자동으로 전송됩니다. 내보내기 화면에는 동기화 버튼이 없습니다.

## 참고 · 확인 팝업
삭제·초기화 같은 확인 창은 브라우저 기본 `confirm()` 대신 **앱 안의 팝업**을 씁니다. 기본 confirm 은 창 위에 `주소 내용:` 이 함께 떠서 어수선하고 글자 크기도 바꿀 수 없기 때문입니다. 사진 삭제 확인은 현장에서 잘 보이도록 **글자를 두 배(26px)** 로 키웠습니다.
